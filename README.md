# El Vuelo del Cóndor y del Águila

*From Material Prison to the Pleroma of Light*

A philosophical, scientific, and mystical web project exploring the intersection of ancient Gnosticism (Sophia and Yaldabaoth) and modern Quantum Physics (Einstein-Rosen bridges and consciousness).

## 🌍 International Collaborations & Translations

We warmly welcome contributions to help translate this project and spread its message globally!

Our project includes two types of localizable assets:
1. **Web Interface & Texts** (`translations/` and `idiomas_data.json`)
2. **Video Subtitles** (`multimedia/srt/` directory, e.g., `es.srt`, `fr.srt`, `en.srt`)

### How to Contribute a Translation

1. **Fork** this repository.

2. **Web Content:** Inside the `translations/` directory, create or edit your language file (e.g., `en.json`). You can use `es.json` as your structural reference. Then update `idiomas_data.json` to enable your language in the switcher.

3. **Subtitles:** Inside the `multimedia/srt/` directory, you can add or update subtitle files (e.g., `en.srt`) for the documentary video.

4. Submit a **Pull Request (PR)** with your changes.

### Terminology Guidelines

Because this work deals with deep gnostic concepts and quantum mechanics, we prioritize conceptual fidelity over literal translation. Please ensure terms like *Pleroma*, *Pneuma*, *Sophia*, *Yaldabaoth*, and the states $\vert \text{UNO} \rangle$ / $\vert \text{EGO} \rangle$ retain their precise metaphysical and mathematical context.

## 🚀 Local Development

To run or test the project locally:

1. Clone the repository.
2. Serve the directory using any local static server (e.g., Live Server in VS Code, Python's `http.server`, or `http-server`).

```bash
python3 -m http.server 8000
```
